# 1988 October Fish Count Report

#ichthyology #marine-biology #volunteer-monitoring #community-science #native-fish-conservation

## Executive Summary

The First Annual 1988 October Fish Count (OFC) was a volunteer-based fish monitoring program organized by the [[Arizona Game and Fish Department]] Nongame Branch. The project recruited 73 participants who sampled 60 sites across [[Arizona]] and [[New Mexico]] during October 1988. The program proved highly cost-effective, costing approximately $2,891.44 compared to an estimated $12,686.40 if conducted by agency staff alone, yielding a savings of $9,794.96. The initiative documented fish communities at diverse aquatic habitats, with strong emphasis on threatened and endangered species—at least one listed taxon was recorded at 34 of 60 sites. The program established a foundation for long-term monitoring of regional fish communities.

## Background & Description

The October Fish Count was modeled after [[Audubon Society]] bird counts, adapting the volunteer citizen science approach to freshwater fish monitoring. The [[Arizona Game and Fish Department]] mailed approximately 225 letters and questionnaires to organizations and individuals throughout Arizona, including National Forest Ranger Districts, Arizona State Parks, Fish and Wildlife staff, wildlife societies, state universities, and sport fisherman groups.

From 73 responses, 61 participants expressed interest, and 21 Team Leaders were selected based on willingness to lead groups, fish identification expertise, and site selection. Team Leaders received questionnaires from potential team members, standardized data sheets with instructions and examples, and equipment loans as needed. A workshop was held September 24-25, 1988, at [[Aravaipa Canyon]] (The Nature Conservancy property) with 30 participants to train volunteers in OFC methodology and introduce them to seven native fish species occurring in the canyon.

Sampling methods included seining, backpack electrofishing, and dip netting. Data collected included species presence, total length measurements (TL in mm), weight (gm), and habitat characteristics. All raw and computerized data (MS-DOS, D-Base III+) were archived in the Nongame Branch, along with detailed maps and photographs from some participants.

## Ecological & Environmental Context

The 60 sampling sites spanned diverse aquatic habitats across [[Arizona]] and adjacent [[New Mexico]], including major river systems ([[Gila River]], [[San Pedro River]], [[Santa Cruz River]], [[East Verde River]]), tributary streams ([[Aravaipa Creek]], [[Tonto Creek]], [[Blue River]], [[Cherry Creek]]), and springs. Habitats ranged from large rivers to small spring-fed streams, representing pool, riffle, and run habitats.

The survey documented a diverse fish assemblage including native species of conservation concern and non-native species. Threatened and endangered species were well-represented, with at least one listed taxon recorded at 34 sites (57% of total). Key threatened native species documented included:

- [[Gila Chub]] (*Gila intermedia*, code *GIRO)
- [[Loach Minnow]] (*Tiaroga cobitis*, code *TICO)
- [[Spikedace]] (*Meda fulgida*, code *MEFU)
- [[Desert Pupfish]] (*Cyprinodon macularius*, code *CYMA)
- [[Gila Topminnow]] (*Poeciliopsis occidentalis*, code *POOC)
- [[Yaqui Chub]] (*Gila purpurea*, code *GIIN)
- [[Little Colorado Spinedace]] (*Lepidomeda vittata*, code *LEVI)
- [[Yaqui Catfish]] (*Ictalurus pricei*, code *ICPR)
- [[Yaqui Sucker]] (*Catostomus bernardini*, code *CABE)
- [[Mexican Stoneroller]] (*Campostoma ornatum*, code *CAOR)

Common native species included [[Longfin Dace]] (*Agosia chrysogaster*, code AGCH), [[Desert Sucker]] (*Pantosteus clarki*, code PACL), [[Sonora Sucker]] (*Catostomus insignis*, code CAIN), and [[Speckled Dace]] (*Rhinichthys osculus*, code RHOS). Non-native species documented included [[Largemouth Bass]] (*Micropterus salmoides*, code MISA), [[Smallmouth Bass]] (*Micropterus dolomieu*, code MIDO), [[Green Sunfish]] (*Lepomis cyanellus*, code LECY), [[Mosquitofish]] (*Gambusia affinis*, code GAAF), and [[Red Shiner]] (*Notropis lutrensis*, code NOLU).

## Key Findings

**Recruitment and Participation:**
- 225 invitation letters mailed; 73 responses received
- 61 participants committed; 21 Team Leaders selected
- 10 individuals could not participate; 2 requested removal from mailing list
- Primary conflict: opening of hunting seasons
- October timing worked well for university class participation
- Workshop at [[Aravaipa Canyon]] (September 24-25) attracted 30 participants

**Cost-Effectiveness:**
- Recruitment cost: $1,106.75 total ($18.14 per volunteer)
- Total volunteer cost including data entry: $25.76 per day (or $30.76 with equipment rental)
- Arizona Game and Fish employee cost: $211.44 per day
- Total OFC program cost: $2,891.44 (94 volunteers × $30.76)
- Comparable agency staff cost: $12,686.40 (60 sites × $211.44)
- **Net savings: $9,794.96** (actual savings higher as agency staff typically work in pairs)

**Survey Coverage:**
- 60 sites sampled across Arizona and New Mexico
- Broad geographic coverage achieved
- 34 sites (57%) contained at least one threatened or endangered species
- Sites included major river systems, tributary streams, and springs

**Species Documentation:**
- Multiple threatened native fish species documented, including [[Gila Chub]], [[Loach Minnow]], [[Spikedace]], [[Desert Pupfish]], [[Gila Topminnow]], [[Yaqui Chub]], [[Little Colorado Spinedace]], [[Yaqui Catfish]], and others
- Common native species well-represented: [[Longfin Dace]], [[Desert Sucker]], [[Sonora Sucker]], [[Speckled Dace]]
- Non-native species presence documented at multiple sites

**Notable Site-Specific Findings:**
- [[Aravaipa Canyon]] sites (multiple locations): documented seven native species including [[Loach Minnow]], [[Spikedace]], [[Gila Chub]], [[Longfin Dace]], [[Desert Sucker]], [[Sonora Sucker]], and [[Speckled Dace]]
- [[Tonto Creek]] (sites 14-16): diverse assemblage including [[Gila Chub]] (threatened), [[Longfin Dace]], [[Sonora Sucker]], [[Desert Sucker]], [[Speckled Dace]], and non-natives
- [[East Verde River]] (sites 17-20): [[Gila Chub]] and [[Roundtail Chub]] (*Gila robusta*, code *XYTE) documented
- [[Burro Creek]] (site 47): 1,101 [[Desert Sucker]] (code NOLU) and 18 [[Smallmouth Bass]]
- [[Fossil Creek]] (site 22): [[Gila Chub]] (10 individuals, 102-205 mm TL, average weight 44.1 gm)
- [[Babocamari]] T-4 Spring (site 42): 496 [[Yaqui Chub]] documented
- [[Turkey Creek]] (site 43): 309 [[Yaqui Chub]] recorded
- [[Pence Draw]] (site 54): multiple threatened species including [[Yaqui Chub]], [[Mexican Stoneroller]], and [[Gila Topminnow]]

**Data Management:**
- All raw and computerized data (MS-DOS, D-Base III+) archived at Nongame Branch
- Detailed maps and photographs provided by some participants
- Standardized species codes developed for database (Appendix A lists codes for all Arizona freshwater fishes)
- Data available to requestors

**Program Value:**
- Established foundation for long-term, comprehensive database on fish community changes
- Provides systematic evaluation of changes across broad sampling of regional habitats over time
- Empirical data more compelling to policymakers than expert opinion and anecdotal data
- Cost-effective method for compiling valuable monitoring data
- Strong volunteer interest and participation demonstrated feasibility

**Future Outlook:**
- Program continuation planned for subsequent years
- Expansion of mailing list encouraged
- Some data from 1988 still outstanding at time of report (May 1989)
- Potential to rival [[Audubon Society]] bird counts in popularity
