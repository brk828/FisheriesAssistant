## Key Findings

1. **Report transmitted:** The Value Engineering Final Report on the Bonita Creek Fish Barrier is forwarded for review.

2. **Accountability report required:** The addressee must consult the project client or user and prepare an accountability report for Robert Owens (LC-6315). The report must classify each proposal as one of the following:
   - **Fully accepted:** accepted with minor or no modifications.
   - **Partially accepted:** accepted with some features withdrawn or rejected.
   - **Withdrawn:** acceptance of another proposal precluded it.
   - **Rejected.**

3. **Justification and savings:** Nonacceptance requires stated reasons for withdrawal or rejection. Full or partial acceptance requires an estimate of savings and/or benefits.

4. **Routing and deadlines:**
   - The accountability report goes to the appropriate Area Office, Project, or Program Manager for review and signature. It is due to the signatory about 60 days before acquisition award or acceptance of services.
   - The signatory then forwards the report and any concurrences or non-concurrences to the Regional Value Program Coordinator, about 15 days before award or acceptance.

5. **Contact:** Questions about the report go to Kevin Kramer at 208-378-5242.

6. **Scope limitation:** The letter contains no quantitative biological data, sample sizes, or statistics, and it does not name any fish species.
