# New Equipment and Software Will Enhance Field Mapping

#resource-management #field-methods #GIS-technology

## Executive Summary

In March 1994, [[Motorola]] and [[GeoResearch Inc.]] donated critical GPS equipment and mapping software to the Cooperative Park Studies Unit at the University of Arizona (CPSU/UA) and the Advanced Resources Technology (ART) program. The donation includes two complete LGT1000 GPS/GIS-receiver field kits, a Motorola Sixgun Base Station, and the complete Geolink Mapping System software suite. This equipment significantly enhances field mapping capabilities for resource management applications and classroom instruction in southeastern Arizona.

## Background & Description

The donated equipment comprises two major components:

**Motorola Hardware Donation:**
- 2 lightweight, battery-powered LGT1000 GPS/GIS-receiver field kits
- 1 Motorola Sixgun Base Station
- Field kit accessories: vehicle antennas and cables, spare NICAD batteries, portable sealed-lead acid batteries, PCMCIA memory cards, computer interface cables, battery chargers, vehicle power adapters, PostPoint differential correction software, and documentation
- Both LGT1000 receivers equipped with embedded [[Geolink Data Collector]]
- Potential for internal radio to receive/send GPS differential correction information

**GeoResearch Inc. Software Donation:**
- Complete PC-based [[Geolink Mapping System]] including:
  - Data Collector module
  - Data Manager module
  - Base Logger module
  - Software keys and manuals
  - Latest version of Raster Background Map module

The [[Geolink Data Collector]] facilitates customization of data collection protocols, enables interactive feature editing, and provides automatic translation of field data to multiple CAD and GIS formats including [[ARC/INFO]], [[AutoCAD]], and [[ERDAS]].

## Ecological & Environmental Context

This technology supports resource management applications across southeastern Arizona ecosystems. The system enables accurate georeferenced digital field data collection and descriptive attribute recording while creating or ground-truthing maps. Users can interact with background maps (scanned quad sheets, historic vegetation maps, or air photos) while simultaneously viewing newly created GPS-produced maps on laptop computers in the field. This capability ensures attribute accuracy and enhances field-mapping productivity for ecological monitoring and natural resource management.

## Key Findings

**Operational Capabilities:**
- The combined GPS hardware and software produce mapping capability that creates field maps quickly, accurately, and economically
- System enables visualization of current position in relation to on-screen digital maps, ensuring attribute accuracy with minimum expense
- Technology integration increases capability to incorporate latest GPS technologies into classroom instruction

**Implementation Timeline:**
- [[Motorola Sixgun Base Station]] expected to be operational by end of semester (Spring 1994)
- Upon full installation of base station, phone lines, and disk drives, GPS base-station files will be available for southeastern Arizona via Internet or modem
