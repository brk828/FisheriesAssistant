# Database Management Program (FY93) — Colorado River Recovery Program

#ichthyology #freshwater-biology #conservation-management #[[Colorado River Endangered Fishes]]

## Executive Summary

This report is **not a species-specific biological study** but an administrative/data-infrastructure project supporting the [[Colorado River Recovery Program]]. Project 22, led by Frank K. Pfeifer and researcher Charles W. McAda of the [[Colorado River Fishery Project]] (U.S. Fish and Wildlife Service), maintains the centralized **Database Management System (DBMS)** for all research and monitoring data on the [[Upper Colorado River Basin]]'s endangered fishes. The program compiles tagging records, catalogs data files submitted by cooperating researchers, distributes [[PIT Tags]] for fish marking studies, and maintains documentation standards across the Recovery Program's data-collection network. FY93 funding was $28,000, fully expended, with no discrepancies reported.

## Background & Description

No morphological, meristic, or anatomical data are presented in this source. The document is administrative in nature and pertains to the **management of datasets** describing endangered fishes rather than direct biological characterization. Species implicitly covered by the Recovery Program's database include the four federally listed [[Colorado River Endangered Fishes]]:
- [[Colorado Pikeminnow]] (*Ptychocheilus lucius*)
- [[Humpback Chub]] (*Gila cypha*)
- [[Bonytail]] (*Gila elegans*)
- [[Razorback Sucker]] (*Xyrauchen texanus*)

No morphometric descriptions of these taxa are provided in this report.

## Ecological & Environmental Context

The database encompasses all research and monitoring data collected under the Recovery Program within the **Upper Colorado River Basin (UCRB)**, covering habitat-use, tagging, and population data for the endangered fish community. The document does not itself describe habitat characteristics, but it functions as the repository underpinning habitat and population assessments conducted by other cooperating projects within the [[Recovery Implementation Program]] (RIPRAP Task V.A.2 — interagency data management).

## Key Findings

- **Study Duration:** Initiated 1986; ongoing as of FY93.
- **PIT Tag Distribution:** 850 [[PIT Tags]] cataloged and distributed to cooperating researchers in FY93 (400 newly purchased; 450 carried over from FY92) for tagging studies on endangered fishes.
- **Tagging Data Compilation:** All endangered fish tagged by investigators (excluding hatchery-held fish) were entered into the UCRB database; minor data-entry discrepancies were identified and corrected.
- **Reporting Delays:** The combined annual tagging list, targeted for an April 1 distribution deadline, was delayed until July 1993 due to late submissions from all contributing investigators. A stricter March 1 deadline was reinstated for 1994.
- **New Data Files:** Approximately 5 new data files were received and cataloged in FY93 (with ~10 accumulated since the last full file-list update in 1991); a comprehensive updated file list was planned for spring 1994.
- **Field Name Standardization:** No updates were needed to the standardized list of database field names used by data-submitting researchers.
- **Documentation:** Updated to reflect newly received files; technical support was provided to Recovery Program cooperators as needed.
- **Budget:** $28,000 provided and fully expended (no variance).
- **Recommendation:** Continuation of the [[Database Management Program]] was recommended as central infrastructure for tracking Recovery Program effectiveness.

## Contextual Notes

This project exemplifies the **data governance backbone** of large-scale, multi-agency endangered species recovery efforts, illustrating how [[PIT Tagging]] programs, standardized metadata practices, and interagency data-sharing protocols (per [[RIPRAP]] Task V.A.2) support long-term monitoring of imperiled riverine fish populations in the [[Colorado River Basin]].
