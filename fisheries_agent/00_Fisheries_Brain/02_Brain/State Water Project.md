# State Water Project

## Summary
The State Water Project is a major water development infrastructure system constructed between 1941-1982 involving thousands of miles of aqueducts. This source describes how it, along with the Central Valley Project, fundamentally altered California's river flow regimes and contributed to the decline of native fish fauna, with agriculture consuming 85% of state water to enable crops like cotton and rice in desert areas.
