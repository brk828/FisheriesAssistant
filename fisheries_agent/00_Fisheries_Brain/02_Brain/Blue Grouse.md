# Blue Grouse

## Summary
Blue Grouse is a native game bird species already permitted for commercial captive propagation in Arizona under regulation R12-4-413. The petition used the existing game bird breeding program, which included Blue Grouse, as a regulatory precedent to argue that native reptiles should similarly be allowed for commercial propagation.
