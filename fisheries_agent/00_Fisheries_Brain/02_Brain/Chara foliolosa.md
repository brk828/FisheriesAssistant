# Chara foliolosa

## Summary
Chara foliolosa is a species from Florida with a chromosome number of n=70, representing the highest chromosome number recorded for any charophyte. This decaploid level (10x the base of 7) was found in a single collection and represents the extreme upper end of ploidy variation in the Chara zeylanica complex.
