# Gerking 1949

## Context
> **Marking Methods:** Fish were anesthetized in 0.5% urethane solution ([[Gerking 1949]] protocol), measured (total length to 0.1 in), and weighed (to 0.01 lb). Trout were jaw-tagged using serially numbered monel-metal strap tags (styles 1005 and 18M, sizes keyed to fish length: No. 1 for 3.5–5.5"...
