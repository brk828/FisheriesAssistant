# Escalante Ranch

## Summary
Escalante Ranch was a candidate restoration site that faced significant selenium contamination concerns requiring Level I, II, and III contaminant assessments. The program determined that selenium contamination issues needed to be resolved before the site could be acquired for restoration purposes.
