# Variational Analysis

## Summary
This source conducts extensive variational analysis using meristic characters including fin-ray counts, scale counts, and vertebral numbers presented in frequency tables (Tables IV-VII). The analysis demonstrates that total dorsal ray count provides 82% correct identification between M. d. velox and M. d. dolomieu with only 16% intergradation, lateral-line scale counts distinguish M. p. henshalli from typical punctulatus, and color pattern variations correlate with habitat, age, and taxonomic identity across all forms.
