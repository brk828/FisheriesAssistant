# Rio Sabinas

## Summary
The Rio Sabinas is a river system in northern Mexico with associated cave systems. This source identifies the Rio Sabinas system as one of the regions containing subterranean waters that harbor specialized cave-adapted fish fauna as part of Mexico's habitat diversity.
