# XSA

## Summary
XSA is a previous stock assessment model used for North-East Arctic cod. This source notes that Fleksibest uses processed data (rather than direct observations) for consistency with XSA and other previous assessment models, though the authors acknowledge this means the statistical properties of the data are unclear or destroyed.

## Context

> **Core Problem Addressed**: Fleksibest addresses the inadequacy of age-structured models for boreal fish stocks that exhibit large inter-annual variation in growth rates.
