# Grand Valley Project Fish Passage

## Summary
Grand Valley Project Fish Passage is a habitat restoration project aimed at restoring fish passage at the Grand Valley Project Diversion Dam. The FY 2000 Recovery Program allocated $1.58 million for this ongoing project as part of efforts to reconnect fragmented critical habitat for endangered fish in the Upper Colorado River Basin.
