# Lake Bonneville Cutthroat

## Summary
Lake Bonneville Cutthroat (Salmo clarkii utah) is a native cutthroat trout subspecies documented in Utah. This source identifies it as one of three native cutthroat subspecies in the state and as an endemic species that evolved in the Bonneville Basin.
