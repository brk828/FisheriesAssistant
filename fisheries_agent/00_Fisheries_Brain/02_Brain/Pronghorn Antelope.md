# Pronghorn Antelope

## Summary
The Pronghorn Antelope (Antilocapra americana mexicanus) is an extirpated species whose reintroduction to Buenos Aires refuge is considered a high priority. The plan calls for forming an interagency release team in the first year to conduct studies and develop a release plan if appropriate and compatible with masked bobwhite objectives.
