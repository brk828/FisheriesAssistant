# Southwest Texas State University

## Summary
Southwest Texas State University is the institution that operated the Aquatic Station where Haideoporus texanus larvae were collected. The university's facility includes the artesian well that provided access to specimens from the Edwards Aquifer.

## Context

> This study describes the larva of *[[Haideoporus texanus]]*, the first hypogeous (subterranean) dytiscid beetle discovered in North America.
