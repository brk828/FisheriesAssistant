# Bryconamericus hyphessus

## Summary
Bryconamericus hyphessus is an existing species to which the new species Bryconamericus novae is allied. However, B. novae differs from B. hyphessus in being less elongate with a more arched dorsal profile and having an additional scale row below the lateral line.
