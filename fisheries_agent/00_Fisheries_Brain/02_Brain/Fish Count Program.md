# Fish Count Program

## Summary
The Fish Count Program is a collaborative monitoring initiative sponsored by the Desert Fishes Council involving participants from Arizona, California, New Mexico, Nevada, Oklahoma, and Texas. The program establishes standardized protocols for monitoring desert fish populations, with flexible sampling methodologies (seining, electrofishing) but required quantification of data, specimen preservation for verification, and data compilation using database software, with sampling conducted during October and results shared at annual Desert Fishes Council meetings.
