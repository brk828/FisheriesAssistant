# Charophyta

## Summary
Charophyta is a separate taxonomic division proposed by some taxonomists (Groves and Bullock-Webster, Zaneveld, and Sachs) to classify charophytes, as an alternative to placing them in the class Charophyceae within Chlorophyta. This classification reflects the distinctive complexity of charophytes that sets them apart from other green algae.
