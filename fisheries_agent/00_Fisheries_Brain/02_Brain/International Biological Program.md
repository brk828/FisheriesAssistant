# International Biological Program

## Summary
The International Biological Program was a large-scale scientific initiative that included a Desert Biome component based at Utah State University. This research proposal planned to utilize computer modeling and simulation programs developed by the International Biological Program's Desert Biome project for analyzing reservoir data.
