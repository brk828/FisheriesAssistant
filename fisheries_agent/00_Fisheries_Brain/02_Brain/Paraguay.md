# Paraguay

## Summary
Paraguay is a country in the La Plata Basin where several Poeciliid species occur. The type specimen of the new species Ilyodon paraguayense was collected from Paraguay, and other species documented from Paraguay include Phalloptychus januarius and Phalloceros caudomaculatus.
