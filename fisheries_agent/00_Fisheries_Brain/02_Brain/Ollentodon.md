# Ollentodon

## Summary
Ollentodon is a goodeid genus placed in the subfamily Girardinichthyinae. This source's preliminary examination suggests that Ollentodon may be synonymous with Skiffia and Neotoca, indicating the current classification contains more genera than justified.
