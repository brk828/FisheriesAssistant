# Orocastus

## Summary
Orocastus is a genus of deltocephaline leafhoppers that this source proposes should include Cabrulus as a subgenus based on remarkable similarities in aedeagal form, style shape, and plate morphology. The new species O. (Cabrulus) pinnipenis is described from this group.
