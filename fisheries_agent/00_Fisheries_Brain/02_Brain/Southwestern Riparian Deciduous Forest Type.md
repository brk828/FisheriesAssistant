# Southwestern Riparian Deciduous Forest Type

## Summary
The Southwestern Riparian Deciduous Forest Type is a vegetation classification to which Bonita Creek's riparian vegetation belongs, specifically the Mixed Broadleaf Series. This forest type has been heavily degraded throughout the Southwest by livestock grazing, altered hydrology, and periodic catastrophic flooding.

## Context

> This 1987 baseline report documents vegetation and breeding bird communities along a 3 km cattle exclosure established in 1984 on [[Lower Bonita Creek]], [[Graham County]], [[Arizona]].
