# I. dugesi

## Summary
Ictalurus dugesi is a catfish species that serves as a reference for taxonomic comparison with unidentified Ictalurus specimens from Balsas tributaries in Morelos. The document notes taxonomic uncertainty regarding these similar specimens that resemble I. dugesi.
