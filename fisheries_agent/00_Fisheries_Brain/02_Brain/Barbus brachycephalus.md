# Barbus brachycephalus

## Summary
Barbus brachycephalus is a cyprinid fish species found in Afghanistan's Amu Darya basin. This source identifies it as one of the species shared between the Amu Darya and Caspian Sea basins, indicating historical connections between these drainage systems.
