# Lake Havasu Fisheries Improvement Partnership Program

## Summary
The Lake Havasu Fisheries Improvement Partnership Program is a multi-faceted project combining recreational fishing habitat enhancement with endangered native fish recovery efforts on Lake Havasu, a Colorado River reservoir. The program includes installing artificial fish habitat structures in 42 coves, constructing shoreline recreational facilities, and establishing up to ten native fish rearing coves to release approximately 60,000 razorback suckers and bonytail chubs into Lake Havasu by 2003.
