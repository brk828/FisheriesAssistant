# Grated Tryonia Snail

## Summary
The Grated Tryonia Snail (Tryonia clathrata) is a hydrobiid snail found in both Pahranagat Valley/White River Valley and the Moapa River area. It was listed twice in the original petition, and the actual number of valid petitioned species was determined to be 30 rather than 31.
