# Chuar Creek

## Summary
Chuar Creek is a tributary in Grand Canyon where temperature measurements documented extreme thermal conditions, with water temperatures reaching 91°F compared to 56°F in the main Colorado River. This temperature gradient data provides environmental context for understanding fish distributions in Grand Canyon tributaries.
