# STReaMS Database

## Summary
The STReaMS Database is a centralized data-sharing system used by multiple agencies to compile and share fish detection and movement data across the Colorado River basin. This study utilized data from this database to track razorback sucker movements at basin scales, combining information from PIT-tag detections and acoustic telemetry across multiple monitoring locations. The authors recommend maintaining and expanding such data-sharing platforms to improve understanding of fish movements across fragmented river systems.
