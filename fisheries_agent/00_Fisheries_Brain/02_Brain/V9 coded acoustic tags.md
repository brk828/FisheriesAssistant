# V9 coded acoustic tags

## Summary
V9 coded acoustic tags are acoustic transmitters operating at 69 kHz frequency that were used to track Northern Pike movements in this study. These tags were attached externally to 15 pike using cinch-up style tags (FT-4) inserted between pterygiophores below the posterior dorsal fin, allowing researchers to track fish movements for up to 7 days following catch-and-release ice angling.

## Context

> **Taxonomic & Life-History Summary**: [[Northern Pike]] (*Esox lucius*) is an important target species for ice angling in northern regions.
