# USFWS Region VI Recovery Implementation Program

## Summary
The USFWS Region VI Recovery Implementation Program is an upper-basin recovery effort for endangered Colorado River fishes that has developed genetic management protocols and research information. This management plan indicates that the lower basin will extensively use information from upper-basin researchers and protocols from this program when developing its own genetic management plans, integrating genetic management efforts across both basins.
