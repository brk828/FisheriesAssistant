# Oaxaca

## Summary
Oaxaca is a Mexican state included in the geographic coverage of this climatological database. The database contains monthly temperature and precipitation records from meteorological stations in Oaxaca as part of the 280 precipitation stations and 92 temperature stations distributed across Mexico from 1947-1988.
