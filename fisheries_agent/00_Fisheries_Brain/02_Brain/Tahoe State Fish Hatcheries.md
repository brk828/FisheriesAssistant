# Tahoe State Fish Hatcheries

## Summary
Tahoe State Fish Hatcheries refers to California fish hatchery facilities in the Lake Tahoe region. These hatcheries, along with Basin Creek, raised a portion of the kokanee salmon fingerlings for the 1950 Lake Tahoe stocking program, supplementing the production from Nevada's Idlewild Hatchery.

## Context

> This 1951 report documents the introduction program of [[Kokanee]] salmon (*Oncorhynchus nerka kennerlyi*), a landlocked form of red salmon, into [[Lake Tahoe]] to restore game fish populations following the decline of native [[Cutthroat Trout]].
