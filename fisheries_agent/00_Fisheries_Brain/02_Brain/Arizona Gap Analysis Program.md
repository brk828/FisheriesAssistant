# Arizona Gap Analysis Program

## Summary
The Arizona Gap Analysis Program is a collaborative effort between the U.S. Fish and Wildlife Service and the University of Arizona that maintains a comprehensive database with geographical analysis capabilities using GIS technology. It served as one of the two primary data sources for the BIOTA Project, providing information on biological communities and species distributions across Arizona.
