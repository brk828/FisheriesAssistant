# Wellton-Mohawk

## Summary
Wellton-Mohawk is an agricultural drainage system whose water currently supports the Cienega de Santa Clara wetland in the Colorado River Delta region. According to the 1999 conference, proposed Salton Sea restoration alternatives included potentially diverting flows from Wellton-Mohawk drainage, which could significantly impact delta ecosystems that depend on these flows.
