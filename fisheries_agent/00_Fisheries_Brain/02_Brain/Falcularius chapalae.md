# Falcularius chapalae

## Summary
Falcularius chapalae is a monotypic cyprinid fish species endemic to Lake Chapala and the upper Santiago River in Mexico's Mesa Central. This source notes that it is closely related to Hybopsis alta and can be separated from it only with great difficulty, raising questions about its generic validity that require systematic resolution.
