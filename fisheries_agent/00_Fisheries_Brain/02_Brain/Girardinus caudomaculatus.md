# Girardinus caudomaculatus

## Summary
Girardinus caudomaculatus is a species name that Eigenmann proved to be generically distinct from Glaridichthys januarius. This species became the type species for the new genus Phalloceros, distinguished by antler-like claspers at the tip of the second prolonged anal ray.
