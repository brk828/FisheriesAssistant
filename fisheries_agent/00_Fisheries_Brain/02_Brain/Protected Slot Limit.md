# Protected Slot Limit

## Summary
A protected slot limit prohibits harvest of fish within a specified size range while allowing harvest of smaller and larger fish. The 508–762-mm protected slot limit for northern pike functioned identically to a 508-mm maximum length limit, showing no advantage over simpler regulations.
