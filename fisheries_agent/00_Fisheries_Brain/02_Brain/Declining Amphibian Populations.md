# Declining Amphibian Populations

## Summary
Declining Amphibian Populations is addressed through a dedicated Task Force within SSC's organizational structure. Task Forces represent a distinct organizational unit alongside the approximately 102 Specialist Groups, with this particular task force focusing on amphibian conservation issues. It is one of only two task forces mentioned, the other addressing invertebrates.

## Context

> This document is a comprehensive member's guide for the [[IUCN]] [[Species Survival Commission]] (SSC) covering the 1994-1996 triennium. The SSC is described as the largest global network of volunteer experts working for species conservation, comprising approximately 5,000 members in 170 countries....
