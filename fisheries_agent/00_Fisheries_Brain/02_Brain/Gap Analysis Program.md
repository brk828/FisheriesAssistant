# Gap Analysis Program

## Summary
The Gap Analysis Program is a U.S. Fish and Wildlife Service initiative that creates comprehensive biodiversity databases with geographical analysis capabilities using Geographic Information System (GIS) technology. In the BIOTA Project, it provided one of two core databases used to identify key biodiversity areas, with project investigators from this program serving as key staff members.
