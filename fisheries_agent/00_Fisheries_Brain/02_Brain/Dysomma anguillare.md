# Dysomma anguillare

## Summary
Dysomma anguillare is another dysommid species mentioned for comparison with Dysommina rugosa. Unlike D. rugosa, which has 4-5 large vomerine teeth, D. anguillare possesses an anterior pair of vomerine teeth that D. rugosa lacks.
