# Arizona Upland Subdivision

## Summary
The Arizona Upland Subdivision is a subdivision of the Sonoran Desertscrub biotic community in which Spur Cross Ranch is located. This habitat type at the site is dominated by triangle-leaf bursage with common associates including foothill paloverde and jojoba, and contains abundant saguaros with densities exceeding 20 per acre in some areas.
