# Allotment Management Plan

## Summary
An Allotment Management Plan is a formal grazing management strategy for public lands that specifies livestock numbers, timing, and pasture rotation systems. The proposed plan for the Dos S Unit would implement a rest-rotation system using seven pastures with an initial stocking rate of 450 cow/bulls, replacing the existing year-round grazing of 650 head, and includes extensive infrastructure development over six years.
