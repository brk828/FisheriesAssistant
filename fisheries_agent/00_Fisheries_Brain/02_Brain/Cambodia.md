# Cambodia

## Summary
Cambodia is the geographic location for one of two empirical applications in this study, specifically analyzing suicide mortality data from newspaper sources. The Cambodian suicide data included 158 observed cases from two newspaper sources, with capture-recapture analysis estimating the true total at 534-539 suicides, indicating that approximately 376-381 suicide deaths went unreported in the newspapers. This application demonstrates the utility of dual system estimation for assessing completeness of mortality surveillance in resource-limited settings.

## Context

> **Core Problem Addressed**: Estimating the size of elusive target populations using dual system (two-source) capture-recapture methods, with focus on improving uncertainty assessment through bootstrap methods when sample sizes are small and asymptotic variance estimates perform poorly....
