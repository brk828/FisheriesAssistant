# Colorado River Fishery Project

## Summary
The Colorado River Fishery Project is a U.S. Fish and Wildlife Service administrative and research initiative that provides data infrastructure and scientific support for the broader Colorado River Recovery Program, which focuses on managing and restoring native fish populations in the Colorado River system. Rather than conducting species-specific biological studies, the project functions as a coordinating framework that collects, manages, and analyzes fishery data to inform conservation and recovery efforts for endangered native fish species such as razorback suckers and bonytail. By supporting field research, aging studies, and monitoring programs, it enables evidence-based management decisions for Colorado River aquatic ecosystem restoration.
