# Wahweap State Fish Hatchery

## Summary
Wahweap State Fish Hatchery is a propagation facility that raises endangered fish species from the Upper Colorado River Basin. The FY 2000 Recovery Program allocated $87,200 for operation and maintenance of this hatchery as part of efforts to propagate endangered fish for recovery purposes.
