# Vinberg

## Summary
Vinberg developed methods for calculating photosynthesis and respiration rates in aquatic systems from diurnal changes in dissolved oxygen concentration. Edwards applied Vinberg's methods (along with Odum's) to measure oxygen dynamics in English chalk streams, using the fundamental equation Q = P + D - R to partition oxygen changes into photosynthesis, respiration, and atmospheric exchange components.
