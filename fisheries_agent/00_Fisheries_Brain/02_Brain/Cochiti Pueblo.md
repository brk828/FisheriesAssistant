# Cochiti Pueblo

## Summary
Cochiti Pueblo is a geographic reference point on the Rio Grande used to describe stream gradient changes. This source notes that stream gradients of 25 feet per mile are common upstream of Cochiti Pueblo, while 5 feet per mile prevail downstream to El Paso, indicating a significant change in river character at this location.
