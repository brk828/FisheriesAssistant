# AIC

## Summary
AIC (Akaike Information Criterion) is a model selection criterion used in the statistical analyses of this study. It was used to select between linear and quadratic regression models examining the effects of fish size on dispersal distance and cumulative path length of Northern Pike following catch-and-release ice angling.

## Context

> **Taxonomic & Life-History Summary**: [[Northern Pike]] (*Esox lucius*) is an important target species for ice angling in northern regions.
