# San Rafael River

## Summary
The San Rafael River is a tributary in the Upper Colorado River Basin where Gila robusta specimens were collected for use as allopatric (geographically separated) comparisons in Rosenfeld's systematics studies. Tyus questioned the rationale for selecting this particular location as the source for representing 'pure' Gila robusta populations in the taxonomic analysis.
