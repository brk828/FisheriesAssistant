# Portuguese Bend

## Summary
Portuguese Bend is an intertidal reef location in Los Angeles County, California where Girella nigricans (opaleye) were collected for this study. The site provided juvenile opaleye ranging from 34.5-73.0 mm standard length that were used in the anesthesia experiments.
