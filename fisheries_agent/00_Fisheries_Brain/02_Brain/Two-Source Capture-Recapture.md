# Two-Source Capture-Recapture

## Summary
Two-source capture-recapture is a population estimation method that uses data from exactly two independent sampling occasions or sources to estimate total population size, including individuals missed by both sources. This source demonstrates applications to suicide data in Cambodia (158 observed, estimated 534-539 total) and heroin users in Thailand (1,447 observed, estimated 4,989-5,000 total). The method requires at least some overlap between sources (n₁₁ > 0) and performs best when sources are independent or show only moderate dependence (odds ratio < 3.5).
