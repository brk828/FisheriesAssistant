# Paranephrops planifrons

## Summary
Paranephrops planifrons is a freshwater crayfish species found in New Zealand. This source describes it as the host species for the newly discovered commensal ostracod Laccocythere aotearoa, with specimens collected from Pelorus Valley, South Island.
