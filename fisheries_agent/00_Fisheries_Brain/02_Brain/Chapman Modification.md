# Chapman Modification

## Summary
The Chapman Modification is an adjusted version of the Peterson method used to estimate population size from mark-recapture data. In this study, it was applied to estimate the razorback sucker population in Lake Mohave using the formula N* = ([M + 1] × [C + 1])/(R + 1), where M is marked fish, C is total captured fish, and R is recaptured marked fish, with confidence limits based on Poisson frequency distribution or Pearson's formula depending on sample size.
