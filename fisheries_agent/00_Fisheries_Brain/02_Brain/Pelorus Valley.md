# Pelorus Valley

## Summary
Pelorus Valley is a location on South Island, New Zealand, and serves as the type locality for Laccocythere aotearoa. This is the only known location where this commensal ostracod has been found on crayfish, though the authors did not revisit this site during their 1967 field expedition.
