# Pickens County

## Summary
Pickens County, Alabama is the type-locality for the new species Saurocythere rhipis. The specimens were collected from a crayfish burrow in a drainage ditch along State Route 14, approximately 0.6 miles southeast of the Alabama-Mississippi state line.
