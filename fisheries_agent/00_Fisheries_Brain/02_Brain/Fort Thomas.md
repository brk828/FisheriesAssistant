# Fort Thomas

## Summary
Fort Thomas is a location on the Gila River in Arizona that has historical significance for the Razorback Sucker. The 1887 type locality (original scientific description location) for the Razorback Sucker is the Gila River at Fort Thomas, which is downstream from the mouth of Eagle Creek.
