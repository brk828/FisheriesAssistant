# Whitlock Valley

## Summary
Whitlock Valley is mentioned as part of the San Simon Project area in Maxwell's 1935 proposal. The San Simon Project was described as extending from Cienega south to Rodeo, New Mexico, and included Whitlock Valley within its boundaries.

## Context
