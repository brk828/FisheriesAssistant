# Lake Panamint

## Summary
Lake Panamint was a Pleistocene lake system that formed part of the interconnected ancient drainage network in the Death Valley region during pluvial periods. Like Lake Manly, this ancient lake system played a critical role in allowing native fishes to disperse and colonize the region before subsequent aridification isolated populations and drove evolutionary divergence.
