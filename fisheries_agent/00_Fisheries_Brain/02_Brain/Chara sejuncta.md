# Chara sejuncta

## Summary
Chara sejuncta is a dioecious species of stonewort in the corticate group of the genus Chara. This study found it has a haploid chromosome number of N=14, consistent with the pattern that dioecious corticate Chara species are haploid while monoecious ones are diploid (N=28).
