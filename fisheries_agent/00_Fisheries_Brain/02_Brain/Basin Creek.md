# Basin Creek

## Summary
Basin Creek is the location of a California state fish hatchery that participated in the Lake Tahoe kokanee introduction program. Along with Tahoe State Fish Hatcheries, it raised a portion of the kokanee fingerlings that were not produced at Idlewild Hatchery for the 1950 stocking effort.

## Context

> This 1951 report documents the introduction program of [[Kokanee]] salmon (*Oncorhynchus nerka kennerlyi*), a landlocked form of red salmon, into [[Lake Tahoe]] to restore game fish populations following the decline of native [[Cutthroat Trout]].
