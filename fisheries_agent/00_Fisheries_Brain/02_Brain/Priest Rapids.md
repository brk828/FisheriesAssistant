# Priest Rapids

## Summary
Priest Rapids is a location on the Columbia River upstream from the Hanford pile areas. It served as a control sampling site in this study, providing background radioactivity measurements for comparison with downstream locations affected by Hanford effluents, with background levels below 10⁻² pc/g.
