# Limicolae

## Summary
Limicolae refers to shorebirds that exhibit coordinated flock movements, such as turning together simultaneously. This source uses them as an example of "lock-and-key reflexes" that produce apparent synchronism through immediate responses to stimuli rather than true rhythmic synchronization, representing a fundamentally different phenomenon from innate rhythmic synchronism.
