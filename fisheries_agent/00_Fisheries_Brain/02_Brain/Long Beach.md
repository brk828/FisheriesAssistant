# Long Beach

## Summary
Long Beach is a California coastal location where the first gempylid fish recorded from California waters was found. In 1932, a specimen of Xenogramma carinatum was found cast up on the strand at Long Beach, preceding the 1942 oilfish record as the only other California gempylid occurrence.
