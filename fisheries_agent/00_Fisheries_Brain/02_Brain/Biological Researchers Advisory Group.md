# Biological Researchers Advisory Group

## Summary
The Biological Researchers Advisory Group (Bio/RAG) is a component of the Colorado River Recovery Implementation Program that provides biological research input to support endangered fish recovery efforts. During the April 1990 meeting, there were concerns about inadequate input from technical experts like the Bio/RAG, leading to discussions about reorganizing the program structure to improve biological guidance to the Management Group.
