# Upper Green River

## Summary
The Upper Green River is a section of the Green River that was part of the Interagency Standardized Monitoring Program for endangered fishes. According to this 1989 meeting agenda, it was one of six river segments where coordinated monitoring efforts were conducted as part of the multi-agency recovery program for endangered Colorado River Basin fishes.
