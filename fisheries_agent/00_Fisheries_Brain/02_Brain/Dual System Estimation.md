# Dual System Estimation

## Summary
Dual system estimation is a capture-recapture approach that uses exactly two independent data sources to estimate the size of hidden or elusive populations by analyzing overlap between sources. This source focuses on dual system methods using the Chapman estimator and its bias-corrected variant, evaluating three bootstrap approaches for constructing confidence intervals when sample sizes are small. The methods assume a closed population with independence between sources (odds ratio = 1), though the study examines performance under varying degrees of source dependence.

## Context

> **Core Problem Addressed**: Estimating the size of elusive target populations using dual system (two-source) capture-recapture methods, with focus on improving uncertainty assessment through bootstrap methods when sample sizes are small and asymptotic variance estimates perform poorly....
