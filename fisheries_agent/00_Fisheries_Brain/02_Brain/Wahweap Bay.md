# Wahweap Bay

## Summary
Wahweap Bay is a location in Lake Powell approximately 1.6 miles upstream from Glen Canyon Dam. This proposal identifies it as one of 14 sampling stations along the reservoir mainstem for the lake-wide monitoring program, representing the downstream end of the monitoring transect.
