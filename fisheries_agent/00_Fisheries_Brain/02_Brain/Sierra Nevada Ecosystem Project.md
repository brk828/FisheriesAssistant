# Sierra Nevada Ecosystem Project

## Summary
The Sierra Nevada Ecosystem Project (SNEP) was a comprehensive assessment to which Moyle contributed during the 1990s. His contributions focused on assessing the status of aquatic habitats, fish populations, and watershed integrity in the Sierra Nevada region.
