# Colorado River Salinity Control

## Summary
The Colorado River Salinity Control project involved converting the earthen Coachella Canal to concrete lining. This fishery inventory was conducted in November 1980 immediately before this conversion, providing unique baseline data to document the fishery resource before habitat modification.
