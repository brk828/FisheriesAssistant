# San Juan River Basin Recovery Implementation Program

## Summary
The San Juan River Basin Recovery Implementation Program is a multi-agency management effort focused on recovering endangered native fishes in the San Juan River. This program conducted large-scale nonnative fish removal operations from 2001-2012, spending $4,218,000 to remove 314,710 Channel Catfish and 20,830 Common Carp, while also stocking over 114,649 Razorback Suckers and 4,000,000 Colorado Pikeminnows.
