# Arizona Black Rattlesnake

## Summary
The Arizona Black Rattlesnake is a viperid snake hypothetically present at the Orme Reservoir site. This source notes it as an example of species normally found in Upper Sonoran or Transition zones that can occur far below typical altitudinal ranges when flowing streams provide suitable mesic habitat corridors.
