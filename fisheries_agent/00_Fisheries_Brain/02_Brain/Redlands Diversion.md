# Redlands Diversion

## Summary
Redlands Diversion is an agricultural diversion structure that creates a passage barrier for endangered fish in the Upper Colorado River Basin. The recovery plan designates construction of passage structures at this location as a Priority 2-3 action to be completed between 1993-1998 to allow fish movement.
