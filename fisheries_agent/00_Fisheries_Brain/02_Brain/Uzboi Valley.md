# Uzboi Valley

## Summary
The Uzboi Valley is a geographic feature that served as a connection between water basins. This source indicates that transgressions linked the Amu Darya basin with the Caspian Sea basin at various times, including at the end of the Pleistocene via the Uzboi Valley.
