# Opsanus tau

## Summary
Opsanus tau is the scientific name for the oyster toadfish, a marine fish species from which the new parasite species Argulus chesapeakensis was collected at Chesapeake Biological Laboratory in Solomons, Maryland. This fish serves as the type host for A. chesapeakensis.
