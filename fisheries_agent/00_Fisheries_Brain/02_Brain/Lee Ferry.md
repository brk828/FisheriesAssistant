# Lee Ferry

## Summary
Lee Ferry is a location on the Colorado River approximately 30 miles upstream from Stanton's Cave in the Grand Canyon region. This source identifies it as a possible source for the parasitic copepod Lernaea cyprinaceae that was found infesting Humpback Chub, potentially introduced via infested hatchery trout released at Lee Ferry.
