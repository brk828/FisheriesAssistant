# Reese River Valley

## Summary
Reese River Valley is a Nevada location that supports Lahontan Cutthroat Trout (Salmo clarki henshawi). This source identifies it as one of the valleys where this fish population would be directly influenced by the MX Missile System construction and groundwater removal.
