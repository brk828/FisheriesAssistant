# Poteau River

## Summary
The Poteau River is an Oklahoma river system mentioned for comparison purposes. As a clear eastern stream, it yielded more fish species in surveys than turbid western streams, following the same pattern observed in the Verdigris River drainage where eastern tributaries were more productive in species diversity.
