# Schistosomiasis

## Summary
Schistosomiasis is a disease in humans caused by a blood fluke that uses Biomphalaria glabrata snails as vectors. Cypretta kawatai has shown effectiveness as a predator of these vector snails in laboratory experiments, indicating potential applications in controlling disease transmission.

## Context
