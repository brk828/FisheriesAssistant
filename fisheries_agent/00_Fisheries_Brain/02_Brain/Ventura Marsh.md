# Ventura Marsh

## Context
> **Habitat:** Clear Lake, a mesotrophic Iowa lake, plus the adjoining shallow (~600 acre) [[Ventura Marsh]], separated from the main lake by a carp trap/dam. Marsh habitat warms earlier in spring than the main lake body.
> -- *[[GrowthOfBluegillLepomisMacroch_1957_08_15]]*
