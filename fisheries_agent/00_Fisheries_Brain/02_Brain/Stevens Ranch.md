# Stevens Ranch

## Summary
Stevens Ranch is a 60-acre property north of Slaughter Ranch that uses alfalfa irrigation. The ranch operates three irrigation wells that draw from the same artesian aquifer system as Slaughter Ranch and influence water production in the shared aquifer.
