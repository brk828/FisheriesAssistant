# Grand Valley Project Diversion

## Summary
The Grand Valley Project Diversion is a water diversion structure requiring fish passage improvements in the Upper Colorado River Basin. The FY 1997 work plan included $50,000 for fish passage construction or planning at this site as part of the habitat restoration program element.
