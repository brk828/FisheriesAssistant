# Electrofishing Protocol

## Summary
Electrofishing is a method for temporarily stunning fish to facilitate capture using electrical current in water. This study used a backpack electrofisher (Smith Root Model 12A POW) with two-pass sampling moving upstream through 37 sites in a 400-m stream section, capturing fish that were then held in mesh laundry baskets for processing before being released at their capture sites.
