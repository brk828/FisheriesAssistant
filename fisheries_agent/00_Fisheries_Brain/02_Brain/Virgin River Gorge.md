# Virgin River Gorge

## Summary
The Virgin River Gorge is a geographic feature on the Virgin River that serves as an important reference point for monitoring the spread of invasive species. According to this 1986 recovery team meeting, Red Shiners were discovered above the Virgin River Gorge, which added urgency to Woundfin recovery efforts as these exotic fish posed a threat to the endangered native species.
