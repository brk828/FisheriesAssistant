# Price-Stubb

## Summary
Price-Stubb is an agricultural diversion structure in the Upper Colorado River Basin that impedes native fish passage. The recovery plan calls for constructing passage structures at this diversion between 1995-1998 as part of habitat restoration efforts for endangered fish species.
