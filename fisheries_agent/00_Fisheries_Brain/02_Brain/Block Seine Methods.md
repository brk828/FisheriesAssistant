# Block Seine Methods

## Summary
Block seining is a technique using mesh nets to prevent fish escape during sampling by blocking off stream sections. This study used 0.6-cm mesh block seines in conjunction with electrofishing to ensure complete capture of fish within sampling sites during the two-pass upstream sampling protocol.
