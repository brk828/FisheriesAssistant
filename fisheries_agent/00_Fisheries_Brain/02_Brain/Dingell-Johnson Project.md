# Dingell-Johnson Project

## Summary
The Dingell-Johnson Project refers to a federal funding program supporting fisheries restoration and management through the Federal Aid to Fish Restoration Act. This study at El Capitan Reservoir was conducted under Dingell-Johnson Project California F-4-D, titled "Stream and Lake Improvement," which provided federal funding for the three-year fisheries management program from 1960-1962.
