# Complex Pulse System

## Summary
Complex Pulse System (CPS) is a specialized type of pulsed direct current electrofishing that delivers three 240-Hz pulses fifteen times per second, resulting in a 12% duty cycle. This source describes it as one of the principal current types used in electrofishing, distinct from standard DC, PDC, and AC systems.
