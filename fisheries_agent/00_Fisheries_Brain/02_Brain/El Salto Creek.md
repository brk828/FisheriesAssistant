# El Salto Creek

## Summary
El Salto Creek is a Mexican stream inhabited by Gila with variable tooth formulae (2,4-4,2 and 1,4-4,1). Populations from this location have very fine scales (68-80 lateral line scales), modal vertebrae count of 42, and no basal radii on scales except on regenerated scales.
