# Escalante State Wildlife Area

## Summary
Escalante State Wildlife Area was one of five priority sites selected for detailed evaluation in the Flooded Bottom Land Restoration Program. A feasibility study was planned for this site, which would require extensive excavation, terracing, and construction work to restore it as razorback sucker habitat.
