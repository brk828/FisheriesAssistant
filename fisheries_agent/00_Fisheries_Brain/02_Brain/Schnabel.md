# Schnabel

## Summary
The Schnabel estimator is a multi-visit mark-recapture method that pools data across k sampling events, calculated as N̂ = Σ(Mₖnₖ)/Σ(mₖ). This study proposes and evaluates a bias-adjusted version N̂ = Σ(Mₖnₖ)/(Σ(mₖ)+1) that becomes approximately unbiased when the geometric mean of sample sizes exceeds 2√N/(k-1), and recommends always using this adjusted version rather than the original formulation.
