# Southwest Missouri State University

## Summary
Southwest Missouri State University is the institutional affiliation of Hsiu-Ping Liu, the co-investigator on this proposal. Liu's laboratory would conduct the DNA sequencing work for the project at a cost of $10 per reaction.
