# El Salto

## Summary
El Salto (or El Salto Creek) is a Mexican waterway that contains Gila populations with variable pharyngeal tooth formulae including both 2,4-4,2 and 1,4-4,1 configurations. Fish from El Salto have fine scales (68-80 lateral line scales), no or very rarely faint basal radii on scales, and a modal vertebrae count of 42.
