# Balsadichthys

## Summary
Balsadichthys is a goodeid genus placed in the subfamily Girardinichthyinae. This source's preliminary examination suggests that Balsadichthys and Ilyodon appear congeneric, indicating that the current classification may over-split genera and requires consolidation.
