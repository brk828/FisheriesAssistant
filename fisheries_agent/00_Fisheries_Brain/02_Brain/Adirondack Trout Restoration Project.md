# Adirondack Trout Restoration Project

## Summary
An experimental fisheries management program that began in 1950 to reclaim former trout waters in the Adirondack Mountains that had been colonized by less desirable species. The project used rotenone to chemically eradicate existing fish populations, followed by restocking with Brook Trout and installation of barrier dams to prevent reintroduction of undesirable species.
