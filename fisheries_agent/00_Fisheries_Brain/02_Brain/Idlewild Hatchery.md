# Idlewild Hatchery

## Summary
Idlewild Hatchery is a fish hatchery facility located in Washoe County near Reno, Nevada. In 1950, this hatchery raised approximately 338,900 kokanee salmon fingerlings from Idaho-sourced eggs as part of the Lake Tahoe stocking program.

## Context
