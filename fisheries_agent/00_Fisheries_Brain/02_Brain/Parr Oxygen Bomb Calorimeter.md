# Parr Oxygen Bomb Calorimeter

## Summary
The Parr Oxygen Bomb Calorimeter is one of three common analytical methods used to measure calorific values of organisms. This compilation notes methodological differences among procedures and uses Parr Instrument Company's standard benzoic acid reference value of 6318 cal/g for calibration.
