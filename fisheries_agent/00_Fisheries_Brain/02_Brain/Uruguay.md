# Uruguay

## Summary
Uruguay is a country in the La Plata Basin where several Poeciliid species occur. Specific locations mentioned include Montevideo and Maldonado, with species like Fitzroya lineata, Phalloptychus januarius, and Cnesterodon decemmaculatus documented from these areas.
