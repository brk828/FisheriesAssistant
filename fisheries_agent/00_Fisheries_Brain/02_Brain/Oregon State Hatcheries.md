# Oregon State Hatcheries

## Summary
Oregon State Hatcheries developed moist pellets made from meats and dry meals that were stored frozen. This source mentions this as an innovation in pelleted feed technology, representing an alternative approach to the dry manufactured pellets that were becoming widespread in federal hatcheries by 1961.

## Context

> This U.S. Fish and Wildlife Service circular (Circular 159, October 1963, with April 1964 correction) provides comprehensive guidance on feeding protocols and nutritional management for hatchery-reared trout.
