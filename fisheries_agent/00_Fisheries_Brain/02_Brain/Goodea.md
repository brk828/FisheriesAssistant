# Goodea

## Summary
Goodea is a goodeid genus placed in the subfamily Goodeinae for which pregnant females have been examined for ovarian structure. This source includes Goodea in the systematic study of Goodeidae, noting that the subfamily Goodeinae appears to be a miscellaneous collection of unrelated morphological types requiring careful analysis.
