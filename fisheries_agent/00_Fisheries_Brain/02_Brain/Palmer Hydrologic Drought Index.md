# Palmer Hydrologic Drought Index

## Summary
The Palmer Hydrologic Drought Index (PHDI) is a drought metric computed alongside PDSI that quantifies moisture deficits affecting hydrological systems. This source computed PHDI values for 18 climatological divisions across Mexico from 1947-1988, using monthly temperature and precipitation data to assess long-term hydrological drought conditions.
