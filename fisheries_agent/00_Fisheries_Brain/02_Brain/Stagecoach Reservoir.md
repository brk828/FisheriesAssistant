# Stagecoach Reservoir

## Summary
Stagecoach Reservoir is an existing water project that depletes 12,800 acre-feet annually from the Yampa River system. This source includes it as part of the environmental baseline condition with a favorable biological opinion, contributing to the total 68,800 acre-feet depletion that flow recommendations must account for while protecting endangered fish.
