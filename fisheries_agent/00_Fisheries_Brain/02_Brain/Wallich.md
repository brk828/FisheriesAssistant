# Wallich

## Summary
Wallich is a researcher who defined the concept of accumulated temperature units in 1901. This source uses Wallich's temperature unit methodology to successfully predict salmon migration timing, finding that peak migration occurred at approximately 1,800 units for chinook and 1,700 units for chum salmon.
