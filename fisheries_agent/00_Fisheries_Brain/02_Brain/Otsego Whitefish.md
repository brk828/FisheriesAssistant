# Otsego Whitefish

## Summary
The Otsego Whitefish is a historical form of whitefish that was described in historical references as "the world's greatest finned table delicacy." It is mentioned as one of the common names for Coregonus clupeaformis. The source provides limited additional detail about this particular whitefish beyond its exceptional reputation for culinary quality.
