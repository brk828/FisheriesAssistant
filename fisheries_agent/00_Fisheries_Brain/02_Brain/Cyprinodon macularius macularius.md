# Cyprinodon macularius macularius

## Summary
Cyprinodon macularius macularius is a subspecies of the Desert Pupfish (Cyprinodon macularius). This fish was included in the draft conservation target list for the Sonoran Desert ecoregional assessment as part of the federally endangered Desert Pupfish species complex.
