# Saddle Island

## Summary
Saddle Island is a geographic feature in Lake Mead. The June 1962 Project Vela Uniform test explosions occurred approximately one mile north of this island in the Vegas Wash Arm.

## Context

> In June 1962, the [[United States Geological Survey]] conducted nine underwater test explosions in [[Lake Mead]] as part of [[Project Vela Uniform]], a continuation of November 1961 tests.
