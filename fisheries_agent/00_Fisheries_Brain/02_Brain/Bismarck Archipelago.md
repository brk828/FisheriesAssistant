# Bismarck Archipelago

## Summary
The Bismarck Archipelago is an island system that has been a key study site in debates about community assembly, particularly in Diamond's 1975 work on assembly rules. This source references the Bismarck Archipelago as an example where the same logical problems about distinguishing random from competition-driven processes apply to debates over species co-occurrence patterns.
