# Interagency Standardized Monitoring Program

## Summary
An Interagency Standardized Monitoring Program is a collaborative framework established among multiple government agencies and institutions to collect fish population data using consistent, uniform methodologies across geographic regions and time periods. This coordinated approach ensures data comparability and reliability for tracking population trends, assessing recruitment bottlenecks, and evaluating conservation outcomes for species of concern, particularly in complex ecosystems like the Colorado River Basin where endangered species management requires long-term, scientifically rigorous monitoring.
