# Gordius

## Summary
Gordius sp. is a nematomorph (horsehair worm) found in Caldwell Hollow as part of the summer-autumn association. Notably, this was one of the very few organisms found in dry soil samples, along with one tendipedid larva, demonstrating some ability to survive in conditions below 100% relative humidity.
