# Lepidostoma

## Summary
Lepidostoma sp. is a caddisfly in Caldwell Hollow that exhibits similar terrestrial aestivation adaptations to Ironoquia punctatissima. Prepupae of this species were found surviving in moist leaf litter during dry periods.
