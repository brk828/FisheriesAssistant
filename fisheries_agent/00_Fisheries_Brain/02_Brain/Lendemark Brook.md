# Lendemark Brook

## Summary
Lendemark Brook is a freshwater stream that flows into the northeastern part of Stege Lagoon, providing freshwater input to the brackish lagoon system. This freshwater input contributes to the salinity dynamics of the lagoon, which normally maintains 8-10 ppt salinity.
