# BORMICON

## Summary
BORMICON is an Icelandic multispecies model that uses the CAGEAN (statistical catch-at-age analysis) framework. This source indicates that Fleksibest was developed as a modification and extension of the BORMICON code, adapting its approach to create an age-length structured model that better addresses the biological realities of stocks with high growth variability.

## Context

> **Core Problem Addressed**: Fleksibest addresses the inadequacy of age-structured models for boreal fish stocks that exhibit large inter-annual variation in growth rates.
