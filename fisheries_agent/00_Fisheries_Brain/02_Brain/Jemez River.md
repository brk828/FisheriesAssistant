# Jemez River

## Summary
The Jemez River basin (HUC8: 13020202) in north-central New Mexico contains the greatest linear extent of suitable habitat for both target species, with 640 km predicted suitable for Rio Grande Chub and 673 km for Rio Grande Sucker. This basin within the Rio Grande/Elephant Butte region represents a priority conservation area for these imperiled desert fishes.
