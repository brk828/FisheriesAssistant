# Charophyceae

## Summary
Charophyceae is a taxonomic class used to classify charophytes (stoneworts) within the division Chlorophyta, following the classification system of G.M. Smith. This proposal uses this classification to place the Characeae, which are simple aquatic plants distinguished from green algae by their distinctive stem node and internode organization, whorled branchlets, and elaborate gametangial structures.
