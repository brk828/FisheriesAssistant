# Gape Limitation

## Summary
Gape limitation refers to the constraint that predators can only consume prey small enough to fit in their mouth opening. This study quantifies gape limitation in white bass using the relationship gape = 0.12(total length) – 1.09, and incorporates it into a consumption function showing that prey vulnerability peaks when prey body depth is half the predator's gape size, with vulnerability declining to zero when prey are too large to be consumed.
