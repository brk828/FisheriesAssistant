# Jicarilla Mountains

## Summary
The Jicarilla Mountains are one of the mountain ranges bounding the Tularosa Basin. This source identifies the Jicarilla Mountains as part of the boundary system for this endorheic basin, which is approximately 150 miles long and 60 miles wide.
