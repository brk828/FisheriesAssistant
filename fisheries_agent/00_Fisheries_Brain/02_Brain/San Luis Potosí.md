# San Luis Potosí

## Summary
San Luis Potosí is a Mexican state included in the geographic extent of this climatological database. The database contains monthly temperature and precipitation records from meteorological stations in San Luis Potosí as part of the comprehensive network covering 18 climatological divisions across Mexico.

## Context
