# Graham Ranch Warm Springs

## Summary
Graham Ranch Warm Springs is a spring location in Big Bend National Park that serves as critical habitat for the endemic Big Bend Mosquitofish (Gambusia gaigei). This source identifies it as the sole remaining native population site for this species, though the population faces endangerment from introduced Common Mosquitofish (Gambusia affinis) at the same location.
