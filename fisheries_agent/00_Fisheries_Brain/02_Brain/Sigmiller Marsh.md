# Sigmiller Marsh

## Summary
Sigmiller Marsh is a wetland area within or connected to the Washington Fields Canal System that is targeted for elimination as part of Red Shiner eradication efforts. The source indicates Utah State University is providing technical assistance for drainage options to eliminate both Sigmiller Marsh and an associated 'Duck Pond' to prevent Red Shiners from bypassing barriers and reaching native fish habitat.
