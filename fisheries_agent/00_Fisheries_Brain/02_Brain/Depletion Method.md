# Depletion Method

## Summary
The Depletion Method is a population estimation technique that calculates total population size based on successive trapping efforts, where the number of animals caught decreases with each round as the population is depleted. In this 1989 Desert Pupfish census, researchers used this method with 42 traps over six successive runs at two-hour intervals, capturing progressively fewer fish in each run (except run four) and temporarily holding captured fish in screened tanks to prevent recapture. This approach was adopted in 1985 with assistance from the University of Arizona as an alternative to earlier mark-recapture techniques, requiring less handling of individual fish.
