# Acanthina angelica

## Summary
Acanthina angelica is a gastropod mollusk documented at Puerto Peñasco, Sonora, Mexico. This source identifies it as part of the intertidal mollusk fauna of the Gulf of California, with identifications made using Keen's "Sea Shells of Tropical West America" and other references.
