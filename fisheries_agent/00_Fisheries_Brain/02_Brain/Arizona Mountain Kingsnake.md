# Arizona Mountain Kingsnake

## Summary
The Arizona Mountain Kingsnake was one of the native reptile species proposed for inclusion in a 1994 captive propagation permit program in Arizona. The proposal suggested a 14-inch size threshold below which captive-bred juveniles could be sold, though Arizona Game and Fish Department staff noted that many wild-caught individuals are naturally smaller than this proposed limit, which would create enforcement problems in distinguishing wild-caught from captive-bred specimens.
