# Grass Valley

## Summary
Grass Valley is a Nevada location that historically supported Rhinichthys osculus reliquus (Grass Valley Speckled Dace), which this source notes is possibly extinct. It is identified as one of the areas that would be directly affected by the MX Missile System project.
