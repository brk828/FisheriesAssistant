# Ashurst-Hayden Diversion

## Summary
Ashurst-Hayden Diversion is a water infrastructure feature on the Gila River. This source mentions it as a downstream boundary for a proposed alternative experimental stocking location for Bonytail Chub, specifically in the reach between Coolidge Dam and this diversion, which was discussed as a more reasonable option than upstream locations near Safford.
