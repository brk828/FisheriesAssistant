# Spring-run Chinook Salmon

## Summary
Spring-run Chinook Salmon is a distinct spawning run of chinook salmon that has experienced catastrophic population decline in California. This source reports it declined from over 1 million spawners to approximately 2,500 fish remaining in only four populations, and it is recommended for endangered species listing in both the Central California and North Coast regional clusters.
