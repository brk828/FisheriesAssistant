# yellow-finned cutthroat trout

## Summary
Yellow-finned cutthroat trout is a native fish species that has been extirpated from Twin Lakes. Along with Colorado cutthroat trout, this native species was eliminated from the system, which now contains introduced species including lake trout, rainbow trout, brown trout, and brook trout.
