# Diamond Y Spring

## Summary
Diamond Y Spring is a spring in Pecos County, Texas, serving as the type locality for Gammarus pecos. This source indicates it produces calcium-sodium sulfatochloride water with salinity of 5.85‰ (miohaline), the highest salinity documented for any population in the complex.
