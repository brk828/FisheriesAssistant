# Grand Valley Project Diversion Dam

## Summary
Grand Valley Project Diversion Dam is a water diversion structure in the Upper Colorado River Basin that blocks fish passage for endangered species. The FY 2000 Recovery Program allocated $1.58 million for fish passage restoration at this dam to restore connectivity in critical habitat areas.
