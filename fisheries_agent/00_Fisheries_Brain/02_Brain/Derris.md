# Derris

## Summary
Derris is a plant genus from which rotenone, the primary piscicide used in California fisheries management, is derived. The roots of Derris plants contain rotenone, which is extracted and formulated into powders (5-20% concentration) or emulsions (~5% concentration) for use in rough fish control operations.
