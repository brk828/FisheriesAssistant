# Riito, Sonora

## Summary
Riito, Sonora is a location marking one end of a 100-kilometer levee system in the Colorado River Delta. This source describes the levee as running from Riito and curving northward toward where Highway 1 bridge washed out below Ledon, with pumping stations along its length managing irrigation drainage water.
