# SALSA

## Summary
SALSA (Semi-Arid Land-Surface Atmosphere) is an existing research program in the Upper San Pedro Basin focused on understanding basin-wide water balance and ecological diversity at multiple temporal scales. According to this proposal, SALSA provides research infrastructure that the transborder watershed program would build upon. The proposal planned to collaborate with the SALSA project in developing a preliminary atlas design for the Upper San Pedro Basin.
