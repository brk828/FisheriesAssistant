# Change-In-Ratio

## Summary
Change-in-ratio is a population estimation method that uses changes in the proportions of different classes (such as males and females) in a population before and after a known removal (typically hunting) to estimate total abundance. This source notes that the method requires recording total kill by class and measuring pre-hunt and post-hunt proportions of each class in the population. The source also cautions that behavioral changes such as post-hunt wariness can affect detection probability and introduce bias into the estimates.
