# Carlin Floy Tags

## Summary
Carlin Floy Tags are external fish identification tags that were used in previous studies on humpback chub in the Little Colorado River. During the 1991 survey, researchers recaptured 42 fish that had been previously marked with these tags, indicating some fish had been tagged in earlier monitoring efforts before the study switched to using PIT tags as the primary marking method.
