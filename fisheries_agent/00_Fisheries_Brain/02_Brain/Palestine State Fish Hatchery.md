# Palestine State Fish Hatchery

## Summary
Palestine State Fish Hatchery is a West Virginia fish production facility that served as the headquarters for this experimental pond management project. The project established experimental ponds within a 50-mile radius of the hatchery to reduce travel time, and two ponds at the hatchery itself were set aside for experimental use, including a 2.2-acre reservoir that was stocked and monitored for population dynamics.
