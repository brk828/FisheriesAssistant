# Page Springs SFH

## Summary
Page Springs State Fish Hatchery is a fish production facility in Arizona used in the endangered species recovery program. According to this 1987 USFWS document, it was designated to receive 100,000 razorback sucker fry and 100,000 Colorado squawfish fry as part of the intermediate rearing strategy for growing endangered fish to predation-resistant sizes before release into natural habitats.
