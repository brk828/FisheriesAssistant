# Babocamari

## Summary
Babocamari is a location in Arizona where T-4 Spring (site 42) was sampled during the 1988 October Fish Count. This site yielded 496 Yaqui Chub, a threatened native fish species.

## Context

> The First Annual 1988 October Fish Count (OFC) was a volunteer-based fish monitoring program organized by the [[Arizona Game and Fish Department]] Nongame Branch.
