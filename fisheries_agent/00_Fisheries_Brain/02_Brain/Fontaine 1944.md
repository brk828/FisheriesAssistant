# Fontaine 1944

## Summary
Fontaine (1944) described spawning behavior in Flathead Catfish (Pilodictis olivaris) and noted behavioral similarities with channel catfish and Brown Bullhead. This source uses Fontaine's indirect observations of non-injected channel catfish to support the conclusion that pituitary injections did not fundamentally alter the species' innate spawning pattern, and cites concordance with Fontaine's description of pre-spawning bottom positioning behavior.
