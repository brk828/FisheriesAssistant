# Ryder (1883)

## Summary
Ryder (1883) documented spawning behavior in Ameiurus albidus, a catfish species related to the channel catfish. This source cites Ryder's work as part of the limited existing literature on ictalurid reproductive biology available prior to this 1957 study.
