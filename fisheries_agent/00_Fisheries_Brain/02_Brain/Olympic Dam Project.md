# Olympic Dam Project

## Summary
The Olympic Dam Project is a mining operation whose environmental impacts on Great Artesian Basin springs are documented in this bibliography. Multiple references from the 1980s-1990s address water extraction threats from mining operations and include environmental impact assessments and conservation recommendations for affected spring ecosystems.
