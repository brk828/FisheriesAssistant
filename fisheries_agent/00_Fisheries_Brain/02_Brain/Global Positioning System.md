# Global Positioning System

## Summary
Global Positioning System (GPS) methods are recommended for implementation in field studies to increase spatial precision of data collection and facilitate data entry into Geographic Information System (GIS) databases. GPS technology would support improved data management and decision-making for razorback sucker recovery efforts.
