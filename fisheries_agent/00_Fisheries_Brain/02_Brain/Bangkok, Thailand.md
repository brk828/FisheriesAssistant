# Bangkok, Thailand

## Summary
Bangkok, Thailand is a location where Gambusia introduction has severely impacted native fish populations. In the canals of Bangkok, the native Aplocheilus panchax has become rare and the endemic Phenacostethus has disappeared, while Gambusia is now common.
