# Jubilee Spring

## Summary
Jubilee Spring (Site #27) was a reintroduction site where the spring was modified in 1987 for a downstream drinker, causing the site to dry. This modification led to the loss of the Gila Topminnow population, and the site met extirpation criteria prior to 1995.
