# Recovery Implementation Program for Endangered Fish Species

## Summary
The Recovery Implementation Program for Endangered Fish Species is a cooperative program in the Upper Colorado River Basin that established requirements for developing protocols to review proposed fish introductions. According to this source, the program's goal is to establish naturally self-sustaining populations of four endangered Colorado River fishes (Colorado squawfish, humpback chub, bonytail chub, and razorback sucker), and it serves as the "reasonable and prudent alternative" for certain water development projects while guiding nonnative fish stocking toward consistency with endangered species recovery.
