# Carbon Dioxide Information Analysis Center

## Summary
The Carbon Dioxide Information Analysis Center (CDIAC) is a data center that co-initiated the Global Historical Climatology Network project with the National Climatic Data Center. CDIAC worked to consolidate disparate global climate datasets into a standardized database to support research on greenhouse gas-induced climate change.
