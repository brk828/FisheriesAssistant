# Colorado River Fishes Project

## Summary
The Colorado River Fishes Project (CRFP) was an earlier baseline study conducted from 1979-1981 that initiated investigations of endangered fish species in the Upper Colorado River Basin. This project was followed by the expanded Colorado River Fishery Monitoring Program (1982-1985), which built upon the CRFP's foundational work with more intensive radiotelemetry and flow-recruitment studies.
