# Tracheliastes polycolpus

## Summary
Tracheliastes polycolpus is a lernaeopodid copepod parasite that infests dace and chub. This source identifies it as one of four lernaeopodid species in the Yorkshire Ouse system and suggests it is probably a comparatively recent introduction to British fauna.
