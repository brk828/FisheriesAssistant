# Cabo Tepoca

## Summary
Cabo Tepoca is a geographic reference point in the Gulf of California used to describe the location where Red Pike-Conger specimens were collected. This source indicates that the collection site near El Desemboque was situated between Santo Tomas and Cabo Tepoca.
