# Soto la Marina

## Summary
Soto la Marina is a Mexican river system where Ictalurus lupus was first documented by Meek in 1904. Like other coastal drainage populations, specimens from this system show relatively high vertebral counts as part of a geographic cline from upstream to downstream/coastal drainages.
