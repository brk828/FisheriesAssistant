# Spring Valley

## Summary
Spring Valley is a Nevada location that contains refuge populations of Pahrump Killifish (Empetrichthys latos latos) and relict dace. This source identifies it as one of the valleys where these transplanted populations would be directly threatened by the MX Missile System project.
