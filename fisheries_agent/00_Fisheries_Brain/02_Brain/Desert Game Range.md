# Desert Game Range

## Summary
Desert Game Range is a USDI-Fish and Wildlife Service property in Clark County, Nevada, that contains Corn Creek Springs. This site has served as one of three managed refugia for the Pahrump Killifish since August 1971, when 29 fish were transplanted there from Manse Spring.
