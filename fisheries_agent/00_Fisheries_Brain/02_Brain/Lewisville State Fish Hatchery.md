# Lewisville State Fish Hatchery

## Summary
Lewisville State Fish Hatchery is a Texas state facility that released 200 largemouth bass fry into Century Lake on the same day as post-treatment monitoring (three weeks after the rotenone treatment). The hatchery was also expected to supply fish for the recommended restocking program, which included largemouth bass, white crappie, and channel catfish.
