# Winter Run Chinook Salmon

## Summary
Winter Run Chinook Salmon (Oncorhynchus tshawytscha) is an anadromous salmonid species that spawns in freshwater and rears in marine environments. This source analyzes the genetically effective population size of Winter Run Chinook populations that include both wild and hatchery-supplemented components, demonstrating that hatchery supplementation can either increase or decrease overall effective population size depending on the relative sizes and proportions of wild versus captive populations.
