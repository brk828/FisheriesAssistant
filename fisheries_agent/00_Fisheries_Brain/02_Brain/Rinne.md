# Rinne

## Summary
Rinne (1984) is cited as arguing that southwestern fish declines result from multiple causes, with ecosystem changes from pristine to disturbed conditions setting the stage for native species decline. This perspective is noted as a limitation of the IFIM methodology, which focuses primarily on physical habitat parameters rather than broader ecosystem changes.
