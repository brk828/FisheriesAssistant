# Capoeta capoeta

## Summary
Capoeta capoeta is a cyprinid fish species present in Afghanistan's Amu Darya basin. This source documents it as one of the species shared between the Amu Darya and Caspian Sea basins, reflecting historical hydrological connections between these drainage systems.
