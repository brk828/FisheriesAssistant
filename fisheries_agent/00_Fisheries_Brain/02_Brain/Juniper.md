# Juniper

## Summary
Juniper is a coniferous tree or shrub genus common in southwestern woodlands. The lecture notes describe Pinyon Pine-Juniper woodlands as very extensive Arizona vegetation with open canopy allowing understory growth, occurring in semi-arid to semi-humid climates but largely modified by grazing.
