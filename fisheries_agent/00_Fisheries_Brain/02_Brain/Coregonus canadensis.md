# Coregonus canadensis

## Summary
Coregonus canadensis is the Atlantic Whitefish, a newly described species by Scott and Klawe in 1967. This checklist documents it as restricted to Nova Scotia waters, representing a significant new species description for Canadian freshwater fishes.
