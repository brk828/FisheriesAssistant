# Geolink Data Collector

## Summary
Geolink Data Collector is a software module embedded in Motorola's LGT1000 GPS receivers that facilitates customization of data collection protocols in the field. It enables interactive feature editing and provides automatic translation of field data to multiple CAD and GIS formats including ARC/INFO, AutoCAD, and ERDAS.
