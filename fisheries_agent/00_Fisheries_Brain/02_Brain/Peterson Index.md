# Peterson Index

## Summary
The Peterson Index (also called the Lincoln Index) is a population estimation method that was used in this survey to calculate nocturnal rodent population sizes. The survey applied it in a modified form using the Schnabel Method to analyze data from live-trapping grids.

## Context

> This is the fourth annual progress report (1979-1982) on a comprehensive mammal survey of the [[George Whittell Wildlife Preserve]] in the [[Aravaipa Creek]] watershed, Arizona.
