# Gypsum Canyon

## Summary
Gypsum Canyon is a location on the Colorado River system where striped bass spawning activity was documented. According to this source, evidence indicated that striped bass spawned between Gypsum Canyon and upper Cataract Canyon, and notably, 40-45 Colorado squawfish (1.5-6 lb) were also found in this same river section.
