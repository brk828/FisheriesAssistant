# Gasterosteus

## Summary
Gasterosteus is a fish genus (sticklebacks) that includes coastal forms found in the Death Valley System. This source identifies its presence in Death Valley as evidence of past hydrological connections between this now-isolated desert system and coastal waters during Pleistocene pluvial periods.
