# Upper Colorado River Recovery Implementation Program

## Summary
The Upper Colorado River Recovery Implementation Program is a recovery effort for endangered fish species in the Upper Colorado River Basin. This source references the program in the context of a genetics study it funded examining potential hybridization between Bonytail Chub and Humpback Chub, noting that the Biological Opinion required reintroduction actions before this study's results were available.
