# Brooks Parsimony Analysis

## Summary
Brooks Parsimony Analysis is one of several biogeographic analytical methods that the investigators incorporated into their revised proposal. This method would be used alongside Component Analysis and COMPARE in MacClade to assess patterns of congruence between organismal phylogenies and biogeographic patterns.
