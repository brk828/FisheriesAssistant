# Phantom Lake Spring

## Summary
Phantom Lake Spring is a spring system in Jeff Davis County, Texas, harboring multiple Gammarus populations. This source documents it as home to the small G. hyalelloides and a larger undescribed population (C) in the canal system, with salinities ranging from 0.123-2.03‰, and notes that population C rarely co-occurs with G. hyalelloides.
