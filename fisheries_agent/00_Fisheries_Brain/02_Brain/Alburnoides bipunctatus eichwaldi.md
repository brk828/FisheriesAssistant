# Alburnoides bipunctatus eichwaldi

## Summary
Alburnoides bipunctatus eichwaldi is a cyprinid fish subspecies found in both the Amu Darya and Caspian Sea basins. The fact that identical subspecies occur in both systems indicates recent connections between these drainage basins.
