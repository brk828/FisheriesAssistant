# Scottsville

## Summary
Scottsville is a location where some of the 65°F and 55°F tests were conducted in 1956. Tests at this location showed elevated pH (8.92) and decreased total alkalinity (36 p.p.m.) due to new transite piping, though this variation did not appear to affect the results.
