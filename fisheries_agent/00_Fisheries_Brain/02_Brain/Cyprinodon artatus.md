# Cyprinodon artatus

## Summary
Cyprinodon artatus is a pupfish species found in the Guzman Basin region. This source indicates it is being studied as part of a taxonomic analysis using 26 morphometric and 21 meristic characters, and researchers suspect that Cyprinodon fontinalis may not be closely related to it despite occurring between artatus drainages, which implies possible Pleistocene sympatry.
