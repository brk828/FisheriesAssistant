# Sacramento Winter-Run Chinook Salmon

## Summary
Sacramento Winter-Run Chinook Salmon is one of four distinct runs of Chinook salmon (Oncorhynchus tshawytscha) in the Sacramento River system, defined by migration timing. This source reports it was listed as endangered by California in 1989 and federally in 1994, with current effective population size estimated at only 200-600 individuals compared to historical run sizes approaching 100,000 fish in the 1960s. The source describes research investigating this run's Major Histocompatibility Complex (MHC) genetic variation and resistance to Rosette Agent parasite, including comparisons with fall-run salmon and experiments using captive broodstock maintained at Bodega Marine Laboratory since 1991.
