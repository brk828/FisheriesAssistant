# Pachycerianthus insignis

## Summary
Pachycerianthus insignis is a cerianthid anemone that lives in a mucus tube embedded in sandstone reef. It has a dark gray column and many very long thin tentacles with longitudinal brown stripes, and exhibits rapid retraction when disturbed.
