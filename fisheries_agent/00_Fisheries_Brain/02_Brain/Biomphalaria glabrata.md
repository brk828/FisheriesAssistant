# Biomphalaria glabrata

## Summary
Biomphalaria glabrata is a freshwater gastropod snail that serves as a vector for the blood fluke causing schistosomiasis in humans. Laboratory experiments demonstrated that Cypretta kawatai is an effective predator of this snail species, suggesting potential for biological control of disease transmission.

## Context
