# Purple-Spined Hedgehog Cactus

## Summary
Purple-Spined Hedgehog Cactus is an endangered cactus that relies on halicitid bee pollinators, which have foraging ranges up to 3 miles from nest areas. Aerial pesticide application would likely jeopardize this species through pollinator mortality, requiring a 3-mile no-aerial-spray buffer or use of alternative control methods like carbaryl bait.
