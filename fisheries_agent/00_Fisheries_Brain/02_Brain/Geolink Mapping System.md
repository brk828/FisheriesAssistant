# Geolink Mapping System

## Summary
Geolink Mapping System is a complete PC-based software suite developed by GeoResearch Inc. for GPS field mapping. The system includes Data Collector, Data Manager, Base Logger modules, and a Raster Background Map module, enabling users to create georeferenced digital field data while viewing background maps on laptop computers in the field.
