# Sheep Corral Canyon

## Summary
Sheep Corral Canyon is a stream that received translocated Gila Trout from Main Diamond Creek as part of replication efforts to expand the species' distribution. Genetic analysis revealed that this population is hybridized with Rainbow Trout, containing alleles characteristic of both species at multiple diagnostic loci, and therefore should not be used as a source population for future recovery efforts.
