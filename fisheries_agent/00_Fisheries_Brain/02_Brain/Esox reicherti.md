# Esox reicherti

## Summary
Esox reicherti is the scientific name for Amur Pike, an Asian species. This source cites its introduction to Pennsylvania as a problematic case where the species has already hybridized with native Northern Pike, illustrating the genetic risks of introducing closely related species.
