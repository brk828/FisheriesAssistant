# Apache Pass

## Summary
Apache Pass marks the northern extent of the Chiricahua Mountains, which extend 35 miles from the San Bernardino drainage to this pass. This source uses it as a geographic boundary marker for describing the mountain ranges bordering San Simon Valley.

## Context
