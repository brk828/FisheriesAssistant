# Crosskey

## Summary
Crosskey (1960) hypothesized that six larval instars are characteristic across the Simuliidae family. This study's confirmation of six instars in Simulium ornatum var. nitidifrons supports Crosskey's generalization, extending evidence beyond Terterjan's earlier work on Wilhelmia equina.
