# Pence Draw

## Summary
Pence Draw is a sampling location (site 54) in Arizona that supported multiple threatened fish species during the 1988 October Fish Count. The site documented Yaqui Chub, Mexican Stoneroller, and Gila Topminnow.

## Context

> The First Annual 1988 October Fish Count (OFC) was a volunteer-based fish monitoring program organized by the [[Arizona Game and Fish Department]] Nongame Branch.
