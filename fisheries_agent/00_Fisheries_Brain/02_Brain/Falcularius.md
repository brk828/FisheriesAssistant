# Falcularius

## Summary
Falcularius is a monotypic cyprinid genus containing only Falcularius chapalae, inhabiting Lake Chapala and the upper Santiago River. This source indicates it is closely related to Hybopsis alta and can be separated only with great difficulty, requiring systematic resolution to determine if it represents a valid genus.
