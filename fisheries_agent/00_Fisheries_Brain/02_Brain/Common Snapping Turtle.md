# Common Snapping Turtle

## Summary
The Common Snapping Turtle is an introduced turtle species in the Arizona-New Mexico reservoir study area. This source identifies it as one of only two species expected to benefit from the proposed reservoir impoundments, suggesting it would thrive in the newly created aquatic habitats.
