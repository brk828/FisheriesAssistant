# IUCN Red Data Book

## Summary
The IUCN Red Data Book provides the major international framework for assessing conservation status of species. Its classification system includes categories such as Extinct, Endangered, Vulnerable, Rare, and Indeterminate, with the critical principle for fish being that the number of sites occupied is more important than total individual numbers since one catastrophic event could eliminate an entire population confined to a single water body.
