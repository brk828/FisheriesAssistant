# Redrock Action Plan

## Summary
The Redrock Action Plan is a June 1990 management plan that prescribes protective measures including livestock exclosures around all three perennial reaches in Redrock Canyon, modified grazing management, and road closures. The biological opinion states that implementation of this plan prior to trail opening is mandatory for the opinion's validity, as the non-jeopardy conclusion assumes these protective measures are already in place.
