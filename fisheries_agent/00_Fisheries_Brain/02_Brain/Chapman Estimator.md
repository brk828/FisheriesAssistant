# Chapman Estimator

## Summary
The Chapman estimator is a statistical formula used to estimate total population size in two-source capture-recapture studies, calculated as N̂_C = [(n₁· + 1)(n·₁ + 1)/(n₁₁ + 1)] - 1, where n₁₁ is the count captured by both sources and n₁·, n·₁ are the marginal totals. This source demonstrates that the Chapman estimator is exactly unbiased when the sum of marginal totals exceeds the true population size, but can show negative bias in very small samples (N < 50), requiring bias-corrected variants. The study shows that bootstrap methods provide better confidence intervals than asymptotic variance formulas, especially for small samples.

## Context

> **Core Problem Addressed**: Estimating the size of elusive target populations using dual system (two-source) capture-recapture methods, with focus on improving uncertainty assessment through bootstrap methods when sample sizes are small and asymptotic variance estimates perform poorly....
