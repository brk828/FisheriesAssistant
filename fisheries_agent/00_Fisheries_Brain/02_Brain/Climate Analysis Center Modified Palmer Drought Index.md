# Climate Analysis Center Modified Palmer Drought Index

## Summary
The Climate Analysis Center Modified Palmer Drought Index (PMDI or CAC) is a variant of the Palmer Drought Severity Index used to quantify moisture deficits. This source computed PMDI values for 18 climatological divisions across Mexico from 1947-1988 as part of a comprehensive suite of drought indices, with archived files labeled as MEX-CAC.RPM.
