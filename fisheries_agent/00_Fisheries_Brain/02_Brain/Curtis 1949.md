# Curtis 1949

## Summary
Curtis 1949 is a previously published taxonomic key that was restricted to a particular taxonomic group of California fishes. This source cites it as an example of earlier keys that had limited taxonomic scope, unlike the comprehensive key covering all freshwater and anadromous species presented in Kimsey and Fisk 1960.
