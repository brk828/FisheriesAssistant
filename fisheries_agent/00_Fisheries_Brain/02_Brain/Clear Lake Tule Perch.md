# Clear Lake Tule Perch

## Summary
Clear Lake Tule Perch (Hysterocarpus traski laguna) is an endemic subspecies of fish found in Clear Lake, California. This source recognizes it as one of the notable endemic taxa within the Sacramento-San Joaquin Province that the classification system explicitly identifies for conservation purposes.
