# Theragra chalcogramma

## Summary
Theragra chalcogramma (Alaska Pollock) represents an important exception to the cerebellar-ecology correlation, possessing an elevated cerebellum despite being morphologically grouped with benthic forms. The author notes this elevated cerebellar structure actually reflects the species' recently discovered midwater pelagic behavior, demonstrating the strong functional relationship between brain structure and locomotor ecology.
