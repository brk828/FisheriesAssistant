# Independence Valley

## Summary
Independence Valley is a Nevada location that supports two endemic fish subspecies: Rhinichthys osculus lethoporus and Gila bicolor isolata. This source identifies it as one of the valleys where these populations would be directly threatened by the MX Missile System construction and groundwater removal.
