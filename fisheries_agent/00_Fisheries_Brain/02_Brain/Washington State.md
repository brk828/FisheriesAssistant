# Washington State

## Summary
Washington State was one of the source locations for Kokanee eggs used in California introductions. This source indicates that eggs from Washington were used for plantings in Strawberry Lake and Donner Lake between 1944-1947, and notes that Washington State favored planting Kokanee at very small sizes (280 per ounce).

## Context

> This 1948 report documents the introduction and establishment of [[Kokanee]] (Oncorhynchus nerka kennerlyi), a landlocked form of [[Pacific Sockeye Salmon]], into California waters beginning in 1941.
