# Point Mugu Naval Base

## Summary
Point Mugu Naval Base was one of several locations where Mike Kunzmann provided technical support for GIS implementation in 1994. The base received assistance as part of CPSU/UA's broader effort to support GIS technology adoption across park units and land management agencies.
