# East Fork Spring

## Summary
East Fork Spring is a water source currently supplying many homes along the East Fork White River, with a flow of approximately 120 gallons per minute (0.3 cubic feet per second). Long-term plans include possibly ceasing diversion of this spring if water distribution is extended to East Fork communities, which would return this flow to the East Fork near the upstream limit of Loach Minnow range.
