# Type Locality

## Summary
Type localities are specified for all four newly described forms: M. p. henshalli from Uphapee Creek, Alabama; M. p. wichitae from West Cache Creek, Wichita Mountains, Oklahoma; M. coosae from Fisher Creek, Alabama; and M. d. velox from Elk River, Oklahoma. This source provides complete morphometric data for holotypes and designates 66-452 paratypes per taxon deposited across multiple museum collections.
