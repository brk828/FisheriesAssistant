# Bear Lake Whitefish

## Summary
Bear Lake Whitefish (Prosopium abyssicola) is a whitefish species endemic to Utah's Bonneville Basin. This source identifies it as one of the native species that evolved in ancient Lake Bonneville, representing a relict population from Pleistocene lake systems.
