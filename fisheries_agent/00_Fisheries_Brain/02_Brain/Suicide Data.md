# Suicide Data

## Summary
Suicide data refers to records of suicide deaths used as an application example in this study, where two newspaper sources in Cambodia were used to identify suicide cases. The analysis found 158 observed suicides across both sources, with the Chapman estimator indicating a total population of 534-539 suicides (95% CI: 358-941 using imputed bootstrap), revealing substantial underreporting in the newspaper sources. This application demonstrates how capture-recapture methods can quantify hidden mortality in populations with incomplete vital registration systems.

## Context

> **Core Problem Addressed**: Estimating the size of elusive target populations using dual system (two-source) capture-recapture methods, with focus on improving uncertainty assessment through bootstrap methods when sample sizes are small and asymptotic variance estimates perform poorly....
