# Colorado River Decision Support System

## Summary
The Colorado River Decision Support System (CRDSS) is a tool for assessing water availability in the Colorado River Basin. In FY 1999, the Recovery Implementation Program allocated $424,000 to use CRDSS for evaluating water availability for instream flows needed to support endangered fish recovery.
