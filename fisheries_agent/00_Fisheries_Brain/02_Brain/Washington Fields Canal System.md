# Washington Fields Canal System

## Summary
Washington Fields Canal System is a canal network where invasive Red Shiners have been documented, creating bypass routes around the Johnson and Washington Fields diversions. The source identifies this as an immediate threat to native fish populations upstream of Washington Fields Diversion and proposes barrier construction above Sigmiller Marsh and chemical treatment of the canal system.
