# Terterjan

## Summary
Terterjan (1957) demonstrated through head capsule measurements that Wilhelmia equina undergoes six larval instars. This pioneering work provided the foundation for Crosskey's hypothesis that six instars are typical across Simuliidae, which the current study further supports.
